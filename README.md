# trimzee

Pune-first real-time salon booking MVP.

## Current MVP
- Responsive customer discovery UI
- Exactly 2 Pune demo salons
- Service + stylist selection
- Available time slots
- Booking confirmation/cancellation demo
- Pay-at-salon flow
- Admin demo dashboard

## Planned integrations
- Supabase Auth/Postgres/Realtime
- Phone OTP provider
- Razorpay test mode
- Real-time database slot locking

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:3000.
